# kpi — 目標・損益分岐・撤退

## 出典

中尾隆一郎『最高の結果を出すKPIマネジメント』（KGI→ギャップ→CSF1つ）。飲食の分解と人時売上・振り返り粒度（そめちゃん『今のKPIで大丈夫？！』）。数字はサーバー確定計算。

## 人が読む要約

KPIは数字の羅列ではない。最終目標、現状との差、現場が動かせる最重要プロセスを1つに絞り、その数値だけを追う。悪化時の打ち手を先に決める。

## 分析パック

- ①KGI（数値と期限。未入力なら未設定）②現状【実績】とのギャップ③プロセス分解④現場が動かせる最重要プロセス（CSF）を1つ⑤その数値目標だけをKPI。
- 指標をたくさん並べて管理しない。KGI未設定なら達成率を作らない。
- 悪化時はいつ・どれくらい・何をする・誰が決める、を判定・中止ラインに書く。
- 販売目標・損益分岐・寄与・上積みはサーバー確定値だけを引用する。AIが別係数で作り直さない。
- 人時売上は総労働時間があるときだけ。業界の合格ラインを当店目標にしない。
