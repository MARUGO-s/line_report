# マネジメント知識倉庫

ベクトル検索のRAGではない。分析AIが毎回全文を読む場所でもない。

## 使い方

1. このフォルダは**人がメンテする出典と要約**（倉庫）。
2. 分析前にモデルへ渡すのは、選ばれた手法の **分析パック** だけ。本文は各ファイルの「分析パック」節。実行時の正本は `supabase/functions/_shared/foodcourt_management_packs.ts`。
3. 数字の正本はコード計算。倉庫の一般論・業界目安を当店の実績や目標にしない。
4. 新しい動画や本は、まずここに要約を足し、分析パックを短く更新してからデプロイする。プロンプトへ原文を貼らない。

## ファイル

| ファイル | 分析手法 |
|---|---|
| `mix.md` | 売上構成・主力商品 |
| `decompose.md` | 客数と客単価の分解 |
| `timing.md` | 時間帯・曜日 |
| `bundle.md` | 同時購入・併売 |
| `event.md` | イベント・天気 |
| `margin.md` | 粗利・採算 |
| `kpi.md` | 目標・損益分岐・撤退 |
| `goal.md` | 改善の打ち手 |

店固有の日報・合意目標などの検索RAGは、この倉庫とは別枠にする。
