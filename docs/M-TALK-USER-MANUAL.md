## 1. 基本を知る

### M-talk は何か

**LINE のような社内チャット**。店舗ごと・プロジェクトごと・部門ごとにグループを作って、
社内メンバーと連絡・情報共有ができます。

| 機能 | 説明 |
| --- | --- |
| グループトーク | 複数人での会話。ルーム単位で管理 |
| 1対1トーク | 1人との個人トーク |
| テキスト | 普通のメッセージ |
| 画像 | 写真・スクリーンショット |
| 感情イラスト | 顔文字の大きい版。39種類から選択 |
| 返信 | 特定のメッセージに返信（スレッド的） |
| リアクション | メッセージに絵文字でリアクション |
| 予約配信 | 日時を指定して後で送信 |
| 通知 | スマホ・PCに通知が来る |

### LINE との違い

LINE Report システムの中には LINE チャットも M-talk も両方あります。**まったく別物** です。

| 項目 | LINE | M-talk |
| --- | --- | --- |
| 主な相手 | 店舗のお客さん | 社内メンバー |
| ログイン | LINE アプリ | メールアドレス + パスワード |
| 利用許可 | 店舗管理 | M-talk 管理者が個別に許可 |
| 止まってもお互い影響なし | 影響なし | **つながらない** |

**大事**: M-talk の利用を止められても LINE は使えます。逆も同じです。

## 2. アカウント登録・ログイン

### 新規登録

1. **M-talk を開く**
   ```
   https://marugo-s.github.io/line_report/chat.html
   ```

2. **「新規登録」をタップ**  
   メールアドレスとパスワード（8 文字以上）を入力

3. **プロフィール設定**（初回のみ）
   - 表示名：社内で呼ばれている名前
   - 所属店舗：複数選べます。1つ以上は必須
   - アイコン：同梱の 70 種類から選ぶか、画像をアップロード

4. **管理者の承認を待つ**  
   登録後、本部管理者が「利用を許可する」まで、M-talk には入れません。  
   許可されると、通知が来て使い始められます。

> **待つ間に できないこと**: メッセージ送受信、ルーム参加、検索

### ログイン

**メールアドレス** と **パスワード** を入力して「ログイン」をタップ。

```
メール: your@example.com
パスワード: ••••••••（8文字以上）
```

**「この端末にメールアドレスを保存する」** にチェックすると、
次回訪問時にメールアドレスが自動入力されます（パスワードは保存されません）。  
**共用端末ではチェックを外してください。**

### パスワードを忘れたとき

申し訳ありませんが、ユーザー側で再設定できません。  
本部管理者に相談してください。

## 3. 画面構成

```
┌─────────────────────────────────────┐
│ ← ヘッダー（ルーム名・メニュー）      │
├──┬─────────────────────────────────┤
│  │  メッセージ一覧                   │
│  │  （いま見ているルームの会話）      │
│左 │                                  │
│側 │                                  │
│  ├─────────────────────────────────┤
│  │  入力欄（ここにメッセージを書く） │
└──┴─────────────────────────────────┘
```

### 左側（ナビレール）

上から順に：

| 要素 | 説明 |
| --- | --- |
| 自分のアイコン | タップするとプロフィール設定 |
| M-talk ロゴ | 全ルーム表示に戻る |
| ベル | 通知のオン・オフ、テスト送信 |

### 中央（トーク一覧）

自分が参加しているルームの一覧。順番は：
- **ピン留め**（お気に入り）が上
- その下は最後にメッセージがあった順

各行には：
| マーク | 意味 |
| --- | --- |
| 📌 | ピン留めされている |
| 🔕 | 通知が切られている |
| 🏪 | 店舗ルーム（固定） |
| BOT | この中に Bot がいる |
| 🗑️ | ゴミ箱に移した |
| 99+ | 未読が 99 件以上 |

### 右側（メッセージ）

選んだルームの会話。スクロールして上へいくと古いメッセージが見える。

## 4. ルームと参加

### ルームとは

**人物グループ（複数人）と 1対1（2人）** の 2 種類。  
グループは自由に作れる（権限がある場合）。

### タブで切り替え

| タブ | 内容 |
| --- | --- |
| **すべて** | 参加しているルーム全部 |
| **友だち** | 1対1トーク相手（未開始の候補も表示） |
| **グループ** | 複数人ルーム |
| **登録ユーザー** | 社内の全メンバー一覧 |
| **Bot** | 店舗 Bot 一覧 |
| **ゴミ箱** | 退出したルーム（復元・削除可） |

> **タブが表示されない場合** → 権限がない。本部管理者に相談。

### ルームに参加する

**グループへの参加**:  
管理者から「参加できるグループ」に見えるルームは、
「参加」ボタンを押しても直接入れません。  
**管理者からの招待リンクが必要**です。

**1対1を始める**:  
「友だち」タブから相手を選んで「1対1」をタップ。

### グループを作る

1. 左下の **「+」** ボタン（FAB = Floating Action Button）をタップ
2. 「新規グループ」を選択
3. グループ名を入力
4. メンバーをチェック
5. 「作成」をタップ

> **「+」が見えない場合** → グループ作成権限がない。本部管理者に相談。

### ルームから退出する

1. ルームの右上の **「⋯」（縦 3 点）** をタップ
2. **「退出」** を選択
3. 確認して「退出」

退出すると、ルール一覧から消えます（ゴミ箱に入ります）。

## 5. メッセージを送る

### テキストを送る

入力欄に文字を打って **送信ボタン** か **Enter キー**。

| デバイス | 送信 | 改行 |
| --- | --- | --- |
| **PC** | Enter キー | Shift + Enter |
| **スマホ** | 送信ボタン | Enter キー |

### 画像を送る

1. 入力欄の **カメラアイコン** をタップ
2. 端末の写真から選ぶか撮影
3. 送信ボタン

または、直接ドラッグ & ドロップ（PC）。

### 感情イラスト（スタンプ）を送る

1. 入力欄の **大きい「☺」** をタップ
2. イラストをタップして選択
3. 「大きく送る」or「文章内に入れる」を選択
4. 送信

39 種類あります。文章に混ぜることもできます。

### メッセージを予約配信する

1. メッセージを打った後、入力欄下の **「予約配信」** をタップ
2. 送りたい **日時** を選択
3. 「予約する」をタップ

その時刻に自動で送信されます。

### メッセージを編集する

自分の **テキスト** だけ編集できます：

1. メッセージにマウスをのせて **「…」（3 点）** をクリック
2. **「編集」** を選択
3. 文字を直して「保存」

古い文章は ~~打消し線~~ で残ります。  
画像・ファイル・カードは編集できません。

## 6. メッセージを読む・操作する

### 既読・未読

スクロールして読んだメッセージは自動で既読になります。

- **未読バッジ** = ルーム一覧に表示される数字
- **チェック マーク** = 自分がそのメッセージまで読んだ位置

### 返信する

特定のメッセージに返信（スレッド的）:

1. メッセージにマウスをのせて **「↙」** をクリック
2. 返信を入力して送信

その返信は、元のメッセージの直下に**インデント**されて表示されます。

### リアクションを付ける

1. メッセージにマウスをのせて **「😊」** をクリック
2. 絵文字を選択

複数人が同じ絵文字でリアクションすると、数字が増えます。

### メッセージをメンション（指名）する

文章の中に **「@名前」** と打つと、その人に通知が届きます。

```
@田中さん、これ確認お願いします
```

### 「最新へ」ボタン

ずっと上の古いメッセージを見ていて、最新に戻したいときに使う。  
**最新到着 50 件が自動取得**されます。

## 7. 1対1トークと友だち

### 友だちを追加する

1. **「友だち」タブ** をタップ
2. **「登録ユーザー」** に未接続の人が表示される
3. 名前をタップして 1対1 を開始

### 新しい 1対1 の条件

以下のいずれかが必要：
- 相手と **同じ店舗に所属**（複数の人は複数の店舗で 1対1 可能）
- 本部管理者からの明示的な許可

> 理由: 無関係な部門同士が勝手に連絡し合わないようにするため

### 1対1を完全に削除する

1対1 トークはゴミ箱には入らず、**完全に削除** できます：

1. 1対1 を開いて右上の **「⋯」** をタップ
2. **「削除」** を選択

削除後、ルール一覧から完全に消えます。  
相手の側には残りません。

## 8. 検索

### メッセージを検索

1. 左側の **虫眼鏡アイコン** をタップ
2. キーワードを入力

**クライアント側**（ローカル検索）:  
- 見ているルームのメッセージ本文
- ルーム名

**サーバー側**（全体検索）:  
- 250ms デバウンス後に自動で実行
- 別枠で検索結果が出る

### 検索結果から飛ぶ

検索結果をタップすると、その場所にジャンプします。  
見ていた位置は保持されるので、「最新へ」で戻せます。

## 9. 通知（Web Push）

### 通知を受け取る

1. **ベルアイコン** をタップ
2. **「通知を有効にする」** をタップ
3. ブラウザの許可ダイアログで「許可」

許可されると、メッセージが来たときにスマホ・PC に通知が届きます。

> **iPhone ホーム画面版だけが対象**。通常の Safari タブでは対応していません。

### 通知テスト

接続・受信がちゃんと動いているか確認：

1. ベルアイコン → **「…」** → **「通知テスト」**
2. テスト通知が届く

テスト通知は設定・権限・メッセージ重複を通りません。  
受け取れればネットワーク OK。

### 通知が来ない場合

| 原因 | 確認方法 |
| --- | --- |
| 通知が切られている | 画面上部の再開バーを見る |
| ブラウザが許可していない | 設定 → 通知をオン |
| iPhone 通常 Safari | 対応していません。ホーム画面に追加してください |
| 端末設定が NO | スマホの設定 → 通知 → M-talk をオン |

**通知テスト**を送ってみて、届くかで切り分けます。

### 通知を切る

1. ベルアイコン → **通知オフ**
2. また来てほしいときは **通知オン**

ルーム側で「通知ミュート」に設定することもできます。

## 10. 予約・予定

### 下部の「予約・予定」タブ

ルーム内の下の方に **2 つのタブ** があります：

| タブ | 内容 |
| --- | --- |
| **予約** | 飲食店の予約（顧客情報） |
| **予定** | カレンダーに登録した予定 |

### 予約を見る

**閲覧のみ** の場合がほとんど。  
ルーム管理者だけが「追加」「編集」「キャンセル」できます。

### 予定を追加する

**ルーム管理者** のみ追加可能：

1. **予定タブ** → **「+」追加**
2. 日付・時刻・タイトル・詳細を入力
3. 保存

### 予定を削除する

1. 予定をクリック
2. **「削除」** をタップ

削除したら、その日付の予定欄から消えます。

## 11. 資料共有・メモ

### 店舗ルームでの「#メモ」機能

店舗の固定ルームで **「#メモ」** と付ければ、
メッセージが自動的に資料として登録されます。

**使用例**:
```
#メモ 本日の売上実績：50,000円
#メモ （画像）- キッチンの改善案
```

### Bot からの結果

#メモ で送信すると：
- テキストは資料に登録
- 画像は自動解析して売上カードを返す
- ファイルは非公開フォルダに保存

### 個人メモ

ルームに送ったメッセージを **「💾」（保存）** でマーク。  
自分の個人メモになり、**他の人には見えません**。

## 12. AIに聞く

### AI ヘルプ（雑談 AI）

1対1 で **店舗 Bot** （ロボットアイコン）を選ぶと、
「M-talk の使い方」「売上検索」「天気」などを AIが答えてくれます。

### 聞けること

| 質問の例 | 答える内容 |
| --- | --- |
| 「画像はどう送る？」 | M-talk の操作手順 |
| 「通知が来ない」 | トラブル対応 |
| 「明日の天気」 | 店舗がある地域の予報 |
| 「売上ランキング」 | 権限がある場合のみ |

### 聞けないこと

- 個人の売上・客数データ（システムの仕組み上見えない）
- M-talk に無い機能（推測しない）
- 営業・経営判断

## 13. 困ったとき Q&A

### ログインできない

```
❌ メールアドレス・パスワードを忘れた
   → 本部管理者に相談

❌ 「利用できません」と出ている
   → 本部が M-talk の利用を止めている
   → 管理者に理由を確認
```

### 「利用できません」と出た

以下のいずれか：

| 状態 | 表示内容 | 原因 |
| --- | --- | --- |
| 利用停止 | 「利用を許可されていません」 | 全体停止 |
| 一時制限 | 「〜まで利用が制限されています」 | 期間限定の停止 |
| 論理削除 | 「削除されたアカウント」 | アカウント削除 |

**対応**: 本部管理者に「使いたい」と申し出てください。

### ルームが見えない

```
❌ 作ったのに見えない
   → 参加申請が承認待ち
   → 管理者から招待リンクをもらう

❌ 昨日まで見えたのに消えた
   → 自分で退出している（ゴミ箱タブで復元可）
   → ルームが削除されている
   → 権限を削除されている
```

**確認**: 「ゴミ箱」タブを見てください。

### メッセージが送信できない

```
❌ 送信ボタンが無い、グレーアウト
   → そのルームに「送信権限」がない
   → 閲覧のみルール
   
❌ 送信ボタンは有るけど何も起こらない
   → ネット接続を確認
   → ページをリロード（F5）
```

### 過去のメッセージが見えない

**仕様です**。ルームに参加した日時より前のメッセージは見えません。  
理由: セキュリティ（参加前の情報保護）

**見たい場合**: 管理者に「過去ログを見たい」と相談。

### 画像が表示されない

1. **画面をリロード**（F5 または再読み込みボタン）
2. **キャッシュをクリア**（設定 → 履歴をクリア）

表示できない画像は自動で署名 URL を作り直します。

### 通知が来ない

**通知テストで切り分け**:

1. ベル → **「…」** → **「通知テスト」**
2. テスト通知が届くか確認

| 結果 | 対応 |
| --- | --- |
| ✅ テスト届く、通常届かない | メッセージ設定を確認 |
| ❌ テスト届かない | ネット・ブラウザ設定確認 |
| iPhone Safari | ホーム画面に追加が必要 |

### iPhone の通知テストでバナーが出ない

バナーは **アプリがバックグラウンド** のときに出ます。  
ホーム画面へ戻って待つと届きます（約 4 秒）。

### 権限を間違えて変えてしまった

1. **管理者に相談**
2. **「監査ログ」から「元に戻す」**

ただし、他の管理者が後から変更していると実行できません。

### 相手を削除・ブロックしたい

M-talk では **ブロック機能がありません**。

**対応**:
- 1対1 は「削除」で完全に消す
- ルームは「退出」して見えなくする（他の人には見える）
- 詳細は管理者に相談

### スマホで文字が小さい

ブラウザの「表示倍率」を大きくしてください。

| ブラウザ | 倍率変更 |
| --- | --- |
| Chrome | メニュー → 設定 → サイトのデータと設定 → ズーム |
| Safari | メニュー → 環境設定 → Webサイト → ズーム |

---

## つながらないとき

1. **ネット接続を確認** → Wi-Fi/4G を確認
2. **M-talk を再読み込み** → ブラウザの再読み込みボタン
3. **ブラウザを再起動** → 完全に閉じて開き直す
4. **キャッシュをクリア** → ブラウザ設定から履歴削除
5. **別のブラウザで試す** → Chrome/Safari 等を試す

**それでもダメ**:  
本部管理者に「M-talk に繋がりません」と報告。

## よくある質問

**Q. 誰まで見える？**  
A. **ルームメンバーだけ**。退出した人には見えません。

**Q. 他人のメッセージを削除できる？**  
A. **いいえ**。自分のテキストだけ編集できます。

**Q. 過去にさかのぼって見える？**  
A. **参加日時から先のみ**。参加前は見えません。

**Q. スマホアプリはある？**  
A. **いいえ**。Web ブラウザのみです。

**Q. LINE と同じ？**  
A. **別物**です。利用許可・アカウント・機能すべて別。

**Q. オフラインで使える？**  
A. **いいえ**。ネット接続が必須。
