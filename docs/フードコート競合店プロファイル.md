# フードコート競合店プロファイル（FOOD STADIUM TOKYO）

マルゴS（MARUGO S）が入る東京ドームシティのフードホール **FOOD STADIUM TOKYO** の各テナント（＝競合）の業態・客単価・特徴をまとめた参照資料。
**フードコート分析の「分析サマリー（自動）」と「データに質問（AI）」は、解析前にこのプロファイルを参照して文脈（業態差・価格帯・飲み/食事傾向）を踏まえた分析を行う。**

- このMDが人間用の正本。コード側は要点を distill して埋め込んでいる（同期先）:
  - AI（Q&A）: [`supabase/functions/_shared/foodcourt_compare.ts`](../supabase/functions/_shared/foodcourt_compare.ts) の `FOODCOURT_STORE_PROFILES` → プロンプトに「競合プロファイル」として注入。
  - 自動サマリー: [`foodcourt.html`](../foodcourt.html) の `STORE_PROFILES` → 分析テキストの【競合環境】章で活用。
- テナントを増減・改装した場合は、このMDとコード2か所の profiles を更新する。
- 調査時点: 2026-06。新規開業店が多く食べログ評点・予算表示は変動しうる。`要現地確認` の項目あり。

## 施設概要（共通前提）

- **施設名**: FOOD STADIUM TOKYO（フードスタジアム東京）
- **所在**: 東京都文京区後楽1-3-61、東京ドームシティ「黄色いビル」2階（JR水道橋駅 徒歩3〜4分）
- **形態**: 約1,470㎡・約480〜500席、**11店舗のセルフ式フードホール**（先決済＋呼び出しベル、**共有客席**）。営業 11:00〜23:00。大型LEDビジョンでスポーツ/エンタメ観戦可。
- **開業**: 第1弾 2024-06-24。一部（チャルモゴッソヨ等）は2025年後半に追加。
- **客層**: 野球・ライブ観戦客、ホテル泊客、インバウンド、競馬ファン（館内WINS後楽園）。イベント前後の飲食需要が大きい（→ 東京ドームのイベント連携・天気連携の分析と整合）。**全店アルコール提供**。
- **競合構造の本質**: 共有席のため席の奪い合いではなく、**同一空間で来場客の「財布」と「滞在時間」を奪い合う**関係。ジャンルは意図的に分散しており直接の同ジャンル競合は少ない。

## 自店（MARUGO S）から見た競合構図

- **客単価ポジション**: ディナー帯は **MARUGO S と A destra Salvatore が施設内の最高単価ゾーン（¥3,000台）**。他は¥1,000〜2,000台中心。→ **客単価の順位は業態差が主因**（ラーメン/ベトナム/もつ鍋＝低単価、ワイン/イタリアン＝高単価）。単価順位の上下より、客単価は「業態として妥当か」で評価すべき。
- **実質的な競合**: 単価ではなく **来場客数（集客）の奪い合い**。客数が弱みなら、同価格帯・同時間帯（特にイベント日・週末夜）の集客が勝負。
- **飲料の住み分け**: アルコールの主役が「ワイン」なのは MARUGO S のみ。ビール＝クラフトビアマーケット/恒久飯店、日本酒＝すしわさび、韓国酒＝チャルモゴッソヨ。**ワイン需要は自店がほぼ独占＝強み**。客単価を支える柱。
- **示唆**: 高単価は業態上の強み。伸びしろは「客数（集客）」。イベント日・週末の取り込み、ワイン×スパイスの体験価値訴求が打ち手。
