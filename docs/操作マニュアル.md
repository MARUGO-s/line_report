# MARUGO 店舗システム 操作マニュアル

LINE と管理画面（売上分析）を使った、売上・レシート・予約・予算の管理マニュアルです。
店舗スタッフ／本部の方向け。困ったときは末尾の「トラブルシュート」を参照してください。

> ⚙️ 不具合・改修の履歴は [`店舗運用修正記録.md`](店舗運用修正記録.md) を参照。

---

## 0. 全体像
- **LINE**：店舗ごとの公式アカウント（ルーム）に **レシート画像・Excel・「予算登録」・予約スクショ・「経費」＋出金レシート** を送ると自動処理。
- **予約**：食べログ/一休の予約メール（Gmail）→ 自動で **LINE通知**。予約メールが来ない予約は **予約画面のスクショ** を送れば登録可（→ 4章）。
- **管理画面（売上分析）**：月間予算・日別配分の設定、各ルームの権限設定、レポート配信先の管理。
- **小口現金（出金・経費）**：レジ出金・経費を記録/集計する専用ページ（→ 9章）。

---

## 1. レシートを登録する（LINE）
1. その店舗のLINEルームに **レシート（精算）画像を送信**。
2. 自動解析され、**売上・組数・客数などのカード**が返ってきます。
3. 数字が違うときは、カードの **「この結果を修正」** ／ **「この解析結果を削除」** ボタンで訂正・削除。
4. **同じ日のレシートを再送**すると「同日のレシートが既に登録されています」と確認が出ます（置き換え等を選択）。

**ポイント**
- 反射・光が強いと読み取りに失敗することがあります。**できるだけ反射の少ない、まっすぐな写真**を。
- 店舗ごとの特殊な様式（例：バルペロタの「通常取引数＝組数」）は専用ルールで対応済み。誤読が続く場合は本部へ。

## 2. 月間予算を登録する（LINE）
> 前提：その部屋で **「予算登録を許可」がON**（管理画面で設定。→ 6章）。

1. LINEルームで **「予算登録」** と送信。
2. **対象の年月を6桁**で送信（例：2026年7月 → **`202607`**）。
3. **予算額（円）を数値**で送信（例：**`1000000`**）。
4. 完了カードが返ります。**「売上分析ページを開く」ボタン**で、続けて曜日重み・休日を設定できます（→ 7章）。

**補足**
- 各カードの **「キャンセル」ボタン**でいつでも中止できます。
- その月に **既に予算がある／売上データがある**ときは、**「上書き保存／キャンセル」**の確認が出ます。
- ここで登録するのは **「月間の総予算額」だけ**です。**曜日ごとの配分や店休日は管理画面で**設定してください（→ 7章）。
- 30分操作がないと自動で受付終了します（その場合は「予算登録」から再開）。

### ⚠️ 数字だけ送ると「売上照会」になります（予算登録と混同しないために）
予算登録と**入力が似ている別機能**があります。**最初に「予算登録」と送ったかどうか**で動作が変わります。

| 送り方 | 結果 |
|---|---|
| **「予算登録」** → 6桁(年月) → 金額 | 月間予算を **登録**（上の手順） |
| いきなり **6桁**（例：`202606`） | その月の **総売上を照会**（登録ではない） |
| いきなり **8桁**（例：`20260618`） | **その日（2026年6月18日）の売上を照会** |

- **予算を登録したいときは、必ず最初に「予算登録」と送ってください。** いきなり数字だけ送ると「売上照会」になり、予算は登録されません。
- 逆に、**売上をサッと見たいだけ**なら「予算登録」と送らず、`202606`（その月の総売上）や `20260618`（その日の売上）だけ送ればOKです。
- ※売上照会は、その部屋で「売上中間報告」または「売上月末レポート」が有効なときに使えます。

## 3. Excelで売上を取り込む（LINE／管理画面）
**テンプレートの形式（新）**
| 位置 | 内容 |
|---|---|
| C3 | **店舗キー**（リストから店舗名を選ぶと自動で入ります） |
| B2 | **対象期間（6桁 YYYYMM）** 例：202506 |
| B3 | 店舗名 |
| A5〜 | 見出し（日付／総売上(税込)／消費税／客数／組数／客単価） |
| A6〜 | 日付と各数値 |

1. このExcelを **LINEルームに送信** するか、**管理画面からアップロード**。
2. **対象期間まるごと置き換え**で登録されます（0・空欄の日は既存データを消去）。
3. 既にデータがある期間は **上書き確認**が出ます。

## 4. 予約通知・予約スクショ取込（LINE）
> 自動：食べログ/一休の予約メール → LINE通知。 手動：予約画面のスクショ → LINEから予約登録（下の「予約スクショから登録」）。

### 予約通知（食べログ／一休・自動）
- 予約メールがGmailに届くと、**自動で**：
  - 店舗のLINEルームへ **予約通知**（新規／変更／キャンセル）。
  - **Googleカレンダー**へ予約を登録。
- 通知には **「予約回数」「キャンセル回数」「過去の予約」** を表示。
  - **予約回数**＝そのお客様の予約の正味数（新規＋1／キャンセル−1）。※「来店したか」ではなく予約ベースの回数です。
  - **キャンセル**：予約回数−1・キャンセル回数＋1。
  - **予約変更**メール：予約回数にはカウントせず、**元の予約を上書き**（カレンダーも重複しない）。

### 予約スクショから登録（手動・手入力の代わり）
食べログ等の予約メールが来ない予約（電話予約・他サイト・店頭予約など）を、**予約管理アプリの「予約確認画面」のスクショ**から登録できます。

1. その店舗のLINEルームに、**予約確認画面のスクリーンショットを送信**。
2. AIが内容を読み取り、**「予約を登録しますか？」確認カード**が返ります（［この内容で登録］／［破棄］）。
3. **「この内容で登録」**を押すと登録完了。**予約表・本日のご予約**に反映され、**予約回数・過去の予約にも算入**されます（メール予約と同じ仕組み）。

**読み取る項目**
- 基本：店舗／**来店日時**／予約者／電話／人数／コース／卓
- メモ系：**アレルギー／苦手・嫌いな食材／記念日（誕生日・バースデー）／メモ（要望・備考）**（記載があるときだけ表示）
- **予約登録日**：画面**左上の日付**（＝予約を登録した日）。**来店日とは別物**として記録します。

**ポイント・注意**
- **「AI返信完全無し」（ハードミュート）でも確認カードは出ます**（登録は明示操作のため）。逆に**無反応のとき**は、その画像がAIに「予約確認画面」と認識されていない可能性 → 反射の少ない、項目がはっきり読める画面で再送してください。
- **「予約回数」に算入されるのは「氏名＋電話番号の両方」が読み取れた予約だけ**です（メール予約と同条件）。**電話番号が画面に無い予約**は、登録・表示はされますが**予約回数にはカウントされません**。
- 同じお客様（**氏名＋電話が一致**）を再登録すると**予約回数が増え**、過去の予約に前回分が並びます。同じスクショを二重に送っても**二重カウントはされません**。
- ※食べログ/一休の自動メール予約とは**カウントが別系統**です（メール予約は食べログ・一休ごと、スクショ取込はまとめて1系統）。

## 5. 本日の予約（毎朝のLINE配信）
- 毎朝、その日の予約一覧がLINEに届きます（お客様名には「様」付き）。
- 配信のON/OFF・送信先は管理画面の設定に従います。

## 6. 管理画面：ルームの権限・機能設定
**場所**：管理画面 →（店舗の）**「権限・機能設定」**。タブ＝レシート関連／カレンダー・予約／その他権限。

**レシート関連タブの主なトグル**
| トグル | 役割 |
|---|---|
| LINE添付保存（ルーム） | 送られた画像等をメディア閲覧に保存 |
| レシートの解析結果を送信 | レシート解析カードを返信する／しない |
| レシート修正の返信を許可 | 「AI返信完全無し」でも修正系の返信は出す |
| 売上中間報告／月末レポート | 各レポートをこのルームに配信 |
| **予算登録を許可** | **このルームから「予算登録」を受け付ける（→ 2章）** |

**保存の注意（重要）**
- 「保存」を押すと、**そのWebhookに連携済みの全ルームへ一括反映**されます。
- **設定を変える前に必ずブラウザを強制再読込（⌘+Shift+R）** してから操作・保存してください（古いページのまま保存すると、設定が正しく保存されないことがあります）。
- 「AI返信完全無し」をONにしても、**レシート解析カードと予算登録の返信は届きます**（必要な返信は止めない設計）。

### 6.5 ルームのスタッフが自分で設定する（セルフ設定・LINEワンパス＋パスワード）
そのルームのスタッフが、フル管理者を介さず**自分のルームの機能ON/OFFだけ**を設定できます（他のルームは触れません）。

**［管理者の準備（最初に1回）］**
1. 管理画面のルーム設定モーダルを開き、対象ルームで **「このルームのセルフ設定を有効化」** をON。
2. **アクセスパスワード**を入力して保存（パスワードはスタッフに口頭等で伝える）。※承認状態や集計店舗の変更はスタッフ側ではできません（管理者専用）。

**［スタッフの使い方］**
1. そのLINEルームで **「設定」** と送信。
2. 届いたボタンから設定ページを開き、**管理者から聞いたパスワード**を入力。
3. 機能のON/OFFを切り替えて **「保存する」**。
- リンクは**24時間・1回のみ**有効。使用済み・期限切れのときは、もう一度ルームで「設定」と送ってください。
- このルームの設定だけが表示・変更できます（他ルームや管理画面全体は開けません）。

## 7. 管理画面：月間予算・日別配分（売上分析）
**場所**：売上分析ページ → 店舗・月を選択 → **「予算・日別配分を設定」**。

設定できる項目：
- **月間予算（円）**：その月の総予算（LINEの「予算登録」と同じ場所に入ります）。
- **曜日ごとの重み**（月〜日）：曜日別の配分比率。
- **国民の祝日／祝日前日の重み**：空欄なら曜日比率と同じ。
- **店舗休日**：チェックした日は配分から除外（その分が他の営業日へ振り分け）。曜日一括指定も可。
- **日別予算（直接入力）**：特定の日だけ金額を直接指定（空欄の日は自動按分のまま）。

**考え方**：月間予算を「曜日の重み＋休日」で各日に配分 → 毎日の売上進捗・着地予測・中間/月末レポートが実態に合います。**LINEで総額を入れたら、ここで曜日重み・休日を必ず設定**してください。

---

## 8. レポート配信
- **売上中間報告**：毎月16日 10:00、指定ルームへ。
- **売上月末レポート**：翌月1日 10:00、指定ルームへ。
- 配信ON/OFF・送信先・時刻は「権限・機能設定」で管理（ルーム個別の時刻設定も可）。

## 9. 小口現金（出金・経費）の記録
レジ出金や経費（例：消耗品の購入）を記録・月集計する専用ページです。**売上・予約とは別管理**です。

- **ページ**：`https://marugo-s.github.io/line_report/petty_cash.html`
- **ログイン**：本部の管理トークン、または管理画面と同じワンタイムリンク（同じトークンを共用）。

**使い方**
1. 上部で **店舗** と **対象月** を選ぶ。
2. 入力フォームに **出金日・品目・勘定科目・価格・取扱者**（メモは任意）を入れて **「追加」**。**税率（8%/10%）は勘定科目から自動表示**（食材→8%・消耗品/アルコール→10%）。出金日の隣の **外税／内税 切替**で価格の扱いを選び（外税＝税抜価格を入力、内税＝税込価格を入力）、**消費税と出金額は自動計算**（税率ごとにまとめて1円未満切り捨て）。
3. 下の **小口表** に一覧表示され、**月合計**と**勘定科目別合計**が出ます。
4. 行の **「削除」** で取り消し（論理削除＝集計から外れます）。

**補足**
- 勘定科目は `消耗品費／食材・仕入／雑費／衛生用品／修繕費／その他`（自由入力も可）。
- 一覧・月集計は **本体／税額／出金額（合計）** を分けて表示します（税額が無いレシートは税0）。
- 「全店舗」を選ぶと店舗列付きで横断表示（追加は店舗を選んでから）。

**LINEから記録（出金レシート）**
1. 店舗のLINEルームで **「経費」**（または「出金」「小口」）と送信。
2. 案内が出たら、**出金（経費）レシートの画像を送信**。AIが本体価格・税額を読み取ります。
3. **確認カード**（店舗／日付／品目／本体／税額／出金額）で **「この内容で記録」** → 小口表に記録（仕入先はメモに保存）。
- ※**「経費」と送ったときだけ**作動します。通常のレシートは従来どおり**売上**として扱われ、経費には紛れません。
- **「経費」と打ち忘れても**：別店舗のレシート（仕入先など）を送ると「店名が異なります」カードに **「経費（小口）として記録」ボタン** が出ます。押すと **内容確認カード**（品目は1項目ずつ表示）が出るので、**「この内容で記録」** で確定します（自店の売上レシートにはボタンは出ません）。
- ※AIの読み取りは**回転・反射に弱い**ことがあります。**確認カードで金額・項目を必ず確認**し、違うときは「破棄」してページから手入力してください。
- 同じ画像を二重に送っても二重記録されません。金額が読み取れないときはページから手入力してください。やめる時は「キャンセル」。

## 10. トラブルシュート
| 症状 | 確認・対処 |
|---|---|
| 「予算登録」の返信が来ない | ①そのルームで **「予算登録を許可」がON** か。②**強制再読込してから保存**したか（→ 6章）。 |
| レシート解析カードが来ない | ①ルームの **「レシートの解析結果を送信」** がON か。②反射の少ない写真で再送。③同日再送は「既に登録済み」確認になる。 |
| 予約通知が来ない／カレンダーに入らない | Gmail連携と定期実行（cron）の稼働を本部で確認。 |
| 予約スクショを送っても無反応／回数が増えない | ①確認カードは「AI返信完全無し」でも出る。出ないなら画像が「予約画面」と認識されていない→反射の少ない、項目が読める画面で再送。②**予約回数は氏名＋電話の両方**が読めた時だけ算入（電話が無い画面は登録・表示はされるが回数は増えない）。 |
| 予約の回数がおかしい | 「予約回数」は予約の正味数（来店有無は見ない）。キャンセルは−1。変更はカウントしない仕様。 |
| Excel取込で店舗がずれる | C3の店舗キー、B2の6桁期間が正しいか確認（リストから店舗名を選ぶとC3が自動入力）。 |

## 11. 用語
- **店舗キー**：店舗の内部識別子（例：barpelota、bistrocavacava）。Excelや予算の照合に使用。
- **小口現金（小口表）**：レジ出金・経費を記録/集計する台帳（売上・予約とは別管理）。
- **予約回数**：お客様の予約の正味数（新規−キャンセル）。来店実績ではなく予約ベース。
- **ワンタイムパスワード付きリンク**：LINEカードから管理画面へ自動ログインする一定時間有効のリンク。
