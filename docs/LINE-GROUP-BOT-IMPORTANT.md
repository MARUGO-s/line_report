# ⚠️ 注意 — グループ／複数人トークと LINE Bot（必読）

> **必ず引っかかるポイントです。**  
> 「グループ参加を許可しているのに Bot がすぐ退出する」「2つ目の Bot を入れられない」といった問い合わせの多くは、**LINE プラットフォームの制限**が原因です。  
> 当システムのバグや「ルーム承認待ち」による **自動退出ではありません**。

## 1. 結論（30秒）

| 質問 | 答え |
|------|------|
| **1つのグループに Bot は何体まで？** | **公式アカウント（Bot）は1体だけ**（LINE の仕様） |
| **2体目を招待すると？** | **参加できず、すぐ消えたように見える**（当方が `leave` しているわけではない） |
| **「グループ参加を許可」が ON なのに消える？** | 多くは **すでに別の Bot がいる** か、**別チャネルの設定だけ ON** |
| **承認待ちで退出する？** | **しない。** グループに残り、**応答・機能だけ止まる** |

## 2. LINE の公式制限（最重要）

### 2.1 1グループ＝1公式アカウント

LINE Messaging API の仕様により、**同じ招待グループ（`C…`）または複数人トーク（`R…`）に参加できる LINE 公式アカウントは1つのみ**です。

- 店舗 Bot（例: バルペロタ）を追加しようとしても、**すでに別の公式アカウントがメンバーにいる**と、2体目は **入れません**。
- 画面上は「招待したのにすぐ退会した」「消えた」ように見えますが、これは **LINE 側で2体目を受け付けない** 動きです。

**当システムのコードには、グループから Bot を追い出す `leave` API 呼び出しはありません。**

### 2.2 「グループ・複数人トークへの参加を許可する」について

LINE Official Account Manager（または LINE Developers）の **Messaging API** にある:

> **グループ・複数人トークへの参加を許可する**

これは **そのチャネル（その Bot）がグループに入ることを許可する** 設定です。

| よくある誤解 | 正しい理解 |
|--------------|------------|
| ON にすれば **何体でも** 入れる | **1グループあたり1体まで** は変わらない |
| 管理 Bot で ON にした | **招待した店舗 Bot のチャネル** で ON か要確認 |
| OFF だから退出した | 参加自体が拒否される（別の症状） |

**確認手順:** 招待する **その Bot 本体** の LINE Developers チャネルを開き、同じ項目が ON か確認する。

## 3. 当システムの「退出」と混同しやすい動作

### 3.1 ルーム承認待ち（当方の機能）

新規に Bot が入った **招待グループ／複数人トーク** は、既定で `bot_access_approved = false`（承認待ち）です。

| 項目 | 動作 |
|------|------|
| グループからの退出 | **しない**（メンバーに残る） |
| レシート・検索など | **動かない**（承認まで停止） |
| 管理 Bot への通知 | 「ルーム承認待ち」カードが届く |
| 解除方法 | 管理 Bot（@392hdime）で **許可ルーム `C…` / `R…`** またはカードの **許可** ボタン |

**見た目:** 「Bot が入ったが何もしない」→ 退出ではなく **承認待ち** の可能性が高い。

### 3.2 比較表

| 症状 | 原因の目安 |
|------|------------|
| 招待直後に **メンバー一覧から消える** | **別 Bot が既にいる**（LINE の1体制限） |
| メンバーに **残るが無反応** | **ルーム承認待ち** または Webhook 403 など |
| 「参加を許可」が **OFF** | そもそもグループ参加不可（チャネル設定） |

## 4. よくある衝突パターン

| パターン | 説明 |
|----------|------|
| **管理 Bot ＋ 店舗 Bot** | 同じグループに @392hdime（管理）とバルペロタ等（店舗）の **両方は入れない** |
| **店舗 A ＋ 店舗 B** | 別店舗でも **公式アカウントが2つ** なら同じグループには不可 |
| **以前試した Bot の残骸** | メンバー一覧に **別の公式アカウント** が残っていないか確認 |
| **設定だけ別チャネル** | バルペロタを入れたいのに、管理 Bot 用チャネルだけ「参加許可 ON」 |

## 5. 運用上の選択肢

| 方針 | 内容 |
|------|------|
| **A. 1つの Bot だけ使う** | そのグループでは **店舗 Bot** か **管理 Bot** か、どちらか一方だけを残す |
| **B. グループを分ける** | 店舗運用用グループ＝店舗 Bot／管理・承認用＝管理 Bot など **用途で分離** |
| **C. 1チャネルに集約** | 複数店舗を同一公式アカウントで運用（ルーム設定で店舗切替）。設計・移行が必要な場合あり |

**推奨（一般的）**

- **レシート・売上・店舗検索** → **店舗 Bot** のグループ  
- **利用許可・ルーム承認** → **管理 Bot** との **1対1** または **管理専用の小さなグループ**（店舗 Bot を入れない）

## 6. 切り分けチェックリスト

| # | 確認 |
|---|------|
| 1 | グループのメンバー一覧で **公式アカウントが1つだけ** か |

## 7. プレゼン・説明用（そのまま読める文）

> **LINE では、1つのグループに入れる公式 Bot は1つだけです。**  
> すでに別の Bot が入っているグループに、バルペロタなど2体目を追加しても、LINE の仕様で参加できず、すぐ消えたように見えます。これは当社システムが退出させているのではなく、LINE の制限です。  
> また、Bot がグループに残っていても反応しない場合は、多くが **ルームの承認待ち** で、管理 Bot から「許可ルーム」で有効化できます。
