GUIDE — JOURNAL REPORT

Journal Report の使い方

POS電子ジャーナル（.jnl / .lzh）から売上レポートを作り、店舗ごとにクラウドへ保存し、AI分析・チャットで振り返るためのアプリです。変換そのものは端末内で行い、保存とAIは認証付きのクラウドAPI経由です。

レジの電子ジャーナルを読み込むと、確定した売上レポートが自動で作られ、クラウドに保存されます。その保存データだけを根拠に、AIが分析や質問応答を行います。AIに計算はさせません。数値はすべてジャーナルから機械的に集計した確定値で、AIはその解釈だけを担当します。

ジャーナルを入れる→レポートが出来る→AIに聞く

02ジャーナルの取り込み（変換タブ）

入れ方

「変換」タブの枠に .lzh / .jnl をドラッグ＆ドロップするか、クリックして選びます。月フォルダごと放り込めば中を再帰的に読みます。

読み込んだ後に自動で起きること

  1. .lzh を解凍し、制御コードを除去して文字コードを変換
  2. 伝票を1件ずつ集計して売上レポートを作成
  3. クラウドへ保存（レポート・詳細HTML・ジャーナル原本）

ここまで自動です。ボタン操作は要りません。

集計のルール

ランチ／ディナー会計時刻 16:00より前がランチ、以降がディナー
カテゴリフード／飲料／室料／その他。チャージは独立カテゴリではなく、実データ上いずれかのカテゴリの内数です（合計に足し戻さないでください）
商品コード分類店舗ごとに調整できます。分類を変えると以後の集計に反映されます
同じファイルの二重取り込みは自動で防ぎます。 内容が同一のファイルは「保管済み」として重複集計されません。集計値が空のまま保存された過去の行は、同じファイルを入れ直すと削除せずに修復されます。
パーサーやカテゴリ定義が更新されると、古いレポートは「旧解析版」と表示されます。AI分析や印刷の前に作り直してください。古い基準のまま比較すると数字がずれます。

施策・イベントカレンダー

日付をクリックして開始日→終了日を選び、施策やイベントを登録します。AIは分析期間と重なる登録を優先して読みます。

ワイン提供量（ml）換算

グラスワイン既定 100ml／点（変更可）
ボトルワイン750ml／点（固定）
ペアリング既定 300ml／点（変更可）
銘柄名だけのボトルは換算に入りません。 対象は「グラスワイン」「ボトルワイン」「ペアリング」に相当する商品だけです。

過去売上への同期

ジャーナルを正として、過去売上（手入力の日次・月次）へ自動反映する設定です。既定はオフで、店舗ごとに明示的に有効化します。

初期値に戻しても、同期設定・カレンダー・ワインml設定は消えません。
05資料タブと LINE #メモ

施策・メニュー・価格改定・現場メモを貯める場所です。AIが「その期間に店舗が何をしていたか」を踏まえて分析できるようになります。

資料は数字の出典にしません。 売上の正本はあくまでジャーナルの確定集計です。資料は背景や要因の説明に使われ、AIは資料由来のとき「登録資料によると」、推測のとき「※これは推測です」と明示します。

LINEから送る

文章のメモ#メモ に続けて本文を送信
写真・PDF先に送ってから、それを引用返信して #メモ
タグ#メモ / #日報 / #note は同じ扱い。全角の ＃ も使えます
写真を送っただけでは登録されません。 LINEの画像メッセージには文字が付かないため、引用返信で #メモ を付ける必要があります。

送信日時が分析の時間軸になります

LINEの送信時刻をそのまま記録し、その日（日本時間）を資料の期間として保存します。深夜0時前後の投稿でも日付がずれません。

分析では、対象期間と重なるメモが必ず参照されます。逆に他の月のメモは、文章が似ていても混ざりません。6月の分析に8月の出来事が紛れ込まないようにするためです。

Webから登録する

種別施策／メニュー／価格改定／イベント／マニュアル／その他
期間開始日・終了日。空欄＝常時有効（グランドメニューやマニュアル向け）
添付画像・PDF・Excel・Word・テキスト等。画像はAIが自動で読み取り、確認画面で修正できます

探す

種別・有効／無効・キーワードに加え、期間で絞り込めます。期間を指定すると、その期間に重なる資料だけが表示されます（常時有効の資料は非表示になります）。

LINE上では一覧を見られません。確認・編集・削除はすべてこの資料タブから行います。削除は既定で論理削除なので、過去の分析結果との整合は保たれます。
06AI分析（標準レポート）

レポートを開いて「AI分析」を押すと、経営・売上の多角分析とワイン営業戦略のレポートが生成されます。履歴は自動保存されます。

AIが必ず突き合わせる3つ

  1. ジャーナルの確定集計（売上・客数・商品・予約など）
  2. 店舗情報（定休・カレンダー・ワインml）
  3. 資料と #メモ（期間が重なるもの）

分析で重視される視点

  • 店舗ごとの立地（新宿三丁目を全店の前提にしません）
  • ランチとディナーを分けた客単価・フード／ドリンク比率
  • ワイン構成、グラスとボトル、提供量(ml)換算
  • 12月のクリスマス要因
  • 定休日を機会損失と誤診しないこと
資料が無い期間は「資料なし」として扱われ、推測で埋めません。分析の質を上げたいときは、その期間の施策やメモを登録してください。
07AIチャット

保存済みレポートとジャーナル全件検索を根拠に質問できます。期間比較、月次推移、商品の点数と売上、客単価、曜日・時間帯、コース、予約と飛び込み、改善案などです。

聞き方の例

  • 2026年6月の売上をまとめて
  • 2024年6月と2025年6月と2026年6月を比較して
  • コース以外のメニューのランキングを10位まで
  • この商品はいつから出している？

聞き返されることがあります

期間対象の年月が分からない、または広すぎるとき
意図何を知りたいか曖昧なとき
ワインの単位「どれくらい出た？」→ 点数／総ml／両方 を確認します

選択肢のボタンで答えられます。答えると、その条件で確定集計を取り直してから回答します。

期間の読み方

「2026年1月から7月まで」は1月〜7月の全月として扱います。両端の2か月だけを見ることはありません。データが無い月だけ「今回の確定集計には表示されていません」と答えます。

回答を残す

回答の下の「📄 PDFにする」で印刷用の表示が開き、同時に質問と回答がクラウドへ保存されます。後から「AIチャットPDF履歴」で見返せます。

08予約・飛び込みと売上予測

予約と飛び込み

チャネル食べログ／一休／手入力
分かること件数・人数・キャンセル・新規／リピート・月次推移・予約内容
飛び込みPOSの組数・客数から予約分を引いた推定値
飛び込みは必ず「推定」です。ノーショー、スクショの送り忘れ、営業日付のズレで実数と一致しません。予約人数をそのまま来店客数として読まないでください。電話予約は集計に含まれません。

利用可能範囲: 現在、予約を加味した集客構造を分析できるのはBistro CAVACAVAの2026年5月以降だけです。4月以前は未取り込みのため予約0件として扱わず、他店舗は予約取り込み未開始のため、この項目自体が出ません。

売上予測とMAPE

カテゴリ分けされた月間レポートの系列から、前年・季節性・直近平均を組み合わせて予測を作ります。後から実績と比べてMAPE（平均絶対パーセント誤差）で精度を確認できます。

10仕組みとデータの扱い

.jnl と .lzh

POSが出す電子ジャーナル（.jnl）は制御コード付きのバイナリログです。.lzh はその圧縮書庫で、アプリが自動で解凍します。

処理の流れは「解凍 → 制御コード除去 → 文字コード変換 → レコード整理 → 売上集計」です。

どこで処理され、どこに残るか

解析お使いの端末内で完結します
保存レポート・AI履歴・予測・資料は、選択中の店舗専用のクラウド領域に保存されます
ジャーナル原本非公開のクラウドストレージ。取得は都度発行の署名付きURL経由

店舗の分離

  • 店舗用ログインでは他店のデータに一切アクセスできません
  • 横断できるのは管理者だけです
  • 公開ページから業務データへ直接つなぐことはなく、必ず認証付きAPIを通ります

AIへ送る個人情報

予約者の氏名は仮名に置き換えて送信します。電話番号は送りません。アレルギーは有無だけを伝え、内容は送りません。

過去売上への同期（ジャーナルを正とする）

電子ジャーナルの確定集計を過去売上へ反映

ON にすると、この店舗でジャーナルレポートを保存したとき、日次・月次の過去売上をジャーナル集計で更新します。既定は OFF です。

AIに渡る前提テキスト（プレビュー）
（保存するとここに表示されます）

実施した施策やメニュー・価格改定を登録しておくと、AIが「その期間に店舗が何をしていたか」を踏まえて売上を分析します。売上の数値は保存済みレポートが正本で、ここに登録した資料は背景の説明にのみ使われます。期間・質問に合う資料だけが根拠候補になり、有効資料の一覧は存在確認用の目次としても渡されますが、目次だけで施策の実施や売上要因を断定しません。

資料を登録

日付を空欄にすると「常時有効」として全期間の売上分析に参照されます（グランドメニュー・マニュアル向け）。画像・PDF・Excel・Word・テキスト・CSV・Markdownを添付すると、Gemini 2.0 Flash が全自動でAI解析し、メニュー名・価格・要約・文字起こし本文・タグを抽出し取り込みます。解析結果は確認ポップアップで手動修正・追記も可能です。
